Dev Icons

A lightweight collection of high-quality SVG icons for developers. This repository serves as a centralized asset library for GitHub READMEs, portfolios, documentation, websites, and other development projects.

✨ Features
🎨 High-quality SVG icons
⚡ Lightweight and scalable
📦 Easy to use with GitHub Raw URLs
🔗 Centralized asset storage
🚀 Perfect for GitHub profile READMEs and project documentation
📁 Structure
icons/
├── eclipse.svg
├── intellij.svg
├── vscode.svg
├── pycharm.svg
├── java.svg
├── python.svg
├── react.svg
├── spring.svg
└── ...

🚀 Usage

Reference any icon directly from GitHub:

<img src="https://raw.githubusercontent.com/<USERNAME>/dev-icons/main/icons/java.svg" width="40" alt="Java">


Example:

<p align="left">
  <img src="https://raw.githubusercontent.com/<USERNAME>/dev-icons/main/icons/java.svg" width="40" alt="Java">
  <img src="https://raw.githubusercontent.com/<USERNAME>/dev-icons/main/icons/spring.svg" width="40" alt="Spring">
  <img src="https://raw.githubusercontent.com/<USERNAME>/dev-icons/main/icons/react.svg" width="40" alt="React">
</p>


Replace <USERNAME> with your GitHub username.
